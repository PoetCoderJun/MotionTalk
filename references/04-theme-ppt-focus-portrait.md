# PPT Focus Portrait / PPT 主视觉竖屏主题

这是可复用的导演 Prompt 参考，适合以 PPT、录屏或报告页面为主要证据，同时保留
口播人物的 3:4 竖屏视频。它描述视觉比例、信息层级和验收门禁，**不是代码模式**，
也不是可直接复制的 Remotion 模板。

## 核心层级

1. **PPT 为第一视觉层级**：完整保留页面宽高比，位于画面中上部并比普通顶贴式
   课件略向视觉中心下沉。
2. 字幕为第二层级：紧接 PPT 下方、画布水平居中；人物和辅助卡不得挤压字幕。
3. 人物为第三层级：使用右下人物窗，脸和身体在裁切内居中，尺寸足以建立信任，
   但不能与 PPT 争夺主视觉。
4. 左下只放当前结论、身份或轻量花字；底部章节进度独立占一条窄轨。

## 3:4 比例起点

下列比例按画布宽高归一化，只是导演计划的起点。根据实际 PPT 可读性和平台安全区
调整，并把最终值写入项目计划。

| 区域 | 建议比例 `x / y / w / h` | 说明 |
|---|---|---|
| 页眉 | `5.6 / 3.6 / 88.8 / 4.6` | 章节、主题和时间，不抢 PPT |
| PPT 舞台 | `5.6 / 13.2 / 88.9 / 37.5` | 16:9 完整显示，不拉伸 |
| 字幕轨 | `5.6 / 51.8 / 88.9 / 9.7` | 与 PPT 约留 1.1% 画布高间距 |
| 左下信息区 | `5.6 / 63.2 / 58.3 / 24.0` | 结论卡或左下花字 |
| 右下人物窗 | `64.8 / 65.6 / 29.6 / 27.8` | 约 4:5，底边高于进度轨 |
| 底部章节进度 | `5.6 / 95.0 / 88.9 / 0.6` | 与人物、字幕分离 |

CTA 可以收窄 PPT，但应保持同一垂直起点；人物窗不要在结尾突然放大。

## 双行自适应字幕

- 字幕严格最多两行，短句保持主字号，长句逐级缩小；禁止出现第三行。
- 优先用实际字体测量或 `@remotion/layout-utils` 计算 fit；缺少测量工具时使用保守
  的中英文加权宽度与原始字符数双重上限。
- 中英文混排允许安全断行，但不得用省略号、line clamp 或裁切来伪装“适配”。
- 每条最多高亮一至两个语义词；字号变化不能改变高亮文字的基线和行高。
- 必须单独抽取全片最长字幕、最长中英混排字幕和结尾字幕证据帧，确认所有字符完整。

## 左下花字

- 身份文字直接落在纯色背景上，不使用大面积底卡。
- 可用粗细对比、单色描边、短下划线、轻微旋转或分段弹入制造创作者感。
- 文案、数字和英文大小写来自项目，不把某个创作者身份写入主题。
- 花字不得进入字幕轨、人物脸或进度轨；出现期间可隐藏同一区域的普通结论卡。

## PPT 与重点框

- 使用最新 PPT/录屏素材；PPT 仍是证据，不重画页面内容。
- 框选只跟随被口播点名的真实对象，不使用装饰性大框。
- 页面、字幕、人物窗和进度必须保持原始比例与独立安全区。

## 必检证据帧

- 开场：PPT、字幕、左下花字和右下人物窗无重叠。
- 最长字幕：完整两行，不得用省略号，不得裁字。
- 关键 PPT 框选：只覆盖对应对象。
- CTA：PPT 仍为主视觉，人物不突增，字幕和进度完整。
