# 参考主题 Prompt

你正在为一条已经精剪并配有最终 SRT 的口播视频设计视觉包装。你可以参考以下效果
快速形成类似视频的导演方向，但它们**不是必选项，也不是代码模式或能力边界**。

## 使用方式

- 用户点名某个参考主题或要求“做成类似效果”时，吸收它的视觉关系与验收重点，
  再根据当前素材重写导演 Prompt。
- 用户没有点名主题时，直接理解其自然语言、样例和素材，不要要求用户选择主题。
- 用户可以混合、删减或完全改写这些效果；自然语言要求与参考主题冲突时，以用户
  当前要求为准。
- 不复制示例文案，不把主题名写成验证器枚举，也不预建四套 Remotion 组件。

## 参考效果 1：floating-overlay

人物或录屏保持全屏，MG 作为透明的标题、关键词、标注或图形悬浮在安全区。
适合画面本身已有信息、只需要轻量强调的短视频。先抽帧确认人脸和关键 UI，再把
可用区域与 forbidden 遮挡写入 Prompt。

## 参考效果 2：mg-with-presenter-window

MG、截图或录屏成为主画面，人物以圆形或方形窗口常驻角落。适合概念解释、数据
拆解和需要保留讲述者陪伴感的内容。人物窗位置、大小与形状由当前画面重算，保持
原始宽高比并避开字幕和关键内容。

## 参考效果 3：switching

人物、全屏 MG 与录屏按内容轮流占据主画面。适合课程、产品演示或素材本身需要
全屏可读的项目。为每次切换写清边界、前后状态与音频连续性；录屏音频默认不用，
唯一主音频仍来自精剪视频。

## 参考效果 4：PPT Focus Portrait

适合以 PPT、录屏或报告页面为主要证据，同时保留口播人物的 3:4 竖屏视频。

### 核心层级

1. **PPT 为第一视觉层级**：完整保留页面宽高比，位于画面中上部并比普通顶贴式
   课件略向视觉中心下沉。
2. 字幕为第二层级：紧接 PPT 下方、画布水平居中；人物和辅助卡不得挤压字幕。
3. 人物为第三层级：使用右下人物窗，脸和身体在裁切内居中，尺寸足以建立信任，
   但不能与 PPT 争夺主视觉。
4. 左下只放当前结论、身份或轻量花字；底部章节进度独立占一条窄轨。

### 3:4 比例起点

下列比例按画布宽高归一化，只是导演计划的起点。根据实际 PPT 可读性和平台安全区
调整，并把最终值写入项目计划。

| 区域 | 建议比例 `x / y / w / h` | 说明 |
|---|---|---|
| 页眉 | `5.6 / 3.6 / 88.8 / 4.6` | 章节、主题和时间，不抢 PPT |
| PPT 舞台 | `5.6 / 13.2 / 88.9 / 37.5` | 16:9 完整显示，不拉伸 |
| 字幕轨 | `5.6 / 51.8 / 88.9 / 9.7` | 与 PPT 约留 1.1% 画布高间距 |
| 左下信息区 | `5.6 / 63.2 / 58.3 / 24.0` | 结论卡或左下花字 |
| 右下人物窗 | `64.8 / 65.6 / 29.6 / 27.8` | 约 4:5，底边高于进度轨 |
| 底部章节进度 | `5.6 / 95.0 / 88.9 / 0.6` | 与人物、字幕分离 |

CTA 可以收窄 PPT，但应保持同一垂直起点；人物窗不要在结尾突然放大。

### 双行自适应字幕

- 字幕严格最多两行，短句保持主字号，长句逐级缩小；禁止出现第三行。
- 优先用实际字体测量或 `@remotion/layout-utils` 计算 fit；缺少测量工具时使用保守
  的中英文加权宽度与原始字符数双重上限。
- 中英文混排允许安全断行，但不得用省略号、line clamp 或裁切来伪装“适配”。
- 每条最多高亮一至两个语义词；字号变化不能改变高亮文字的基线和行高。
- 必须抽取全片最长字幕、最长中英混排字幕和结尾字幕证据帧，确认字符完整。

### 左下花字与 PPT 重点框

- 身份文字直接落在纯色背景上，不使用大面积底卡。
- 可用粗细对比、单色描边、短下划线、轻微旋转或分段弹入制造创作者感。
- 使用最新 PPT/录屏素材；框选只跟随被口播点名的真实对象，不用装饰性大框。
- 花字和重点框不得进入字幕轨、人物脸或进度轨。

### 必检证据帧

- 开场：PPT、字幕、左下花字和右下人物窗无重叠。
- 最长字幕：完整两行，不得用省略号，不得裁字。
- 关键 PPT 框选：只覆盖对应对象。
- CTA：PPT 仍为主视觉，人物不突增，字幕和进度完整。

## 参考效果 5：Close Evidence Portrait / 近景证据流

这是 Jun 近期发布视频的主要主题。适合 3:4 竖屏口播，以真实录屏、页面、表格或
结果为主卡，同时用向上悬挑的头肩近景人物建立陪伴感。主题的核心不是固定坐标，而是
**主卡接近几何中心，整组内容达到视觉居中；人物更近，证据更大，底部更清楚。**

### 视觉重心

- 主卡保持原始宽高比，宽度通常占画布 `88%–91%`；中心可位于距顶部
  `45%–51%`。其中 `45%` 等价于距底部约 `55%`，表示主卡最多可从几何中心向上
  修正约 5% 画布高。
- 不以主卡坐标单独判断居中。人物窗、字幕、阴影和章节进度共同形成的视觉重心应落在
  距顶部 `48%–50.5%`。
- 人物窗默认贴近主卡右上边缘并明显向上悬挑，建议起点为
  `x 71%–73% / y 24%–26% / w 25%–27% / h 19%–22%`；关键 UI 位于右上时可镜像到左上。
- 人物裁成头肩近景，眼睛位于人物窗高度约 `30%–38%`。人物窗接近方形或轻微竖向，
  不要让远景人物独立沉在右下角。

### 三种语义状态

1. **亲近讲解态**：主卡居中，人物向上悬挑并与主卡轻微压边；用于开场、背景和过渡。
2. **证据放大态**：遇到“看这里”“真正的问题”“关键是”等句子时，主卡扩大到画布宽
   `104%–112%`，允许溢出默认框；缩放和局部平移必须对准真实 UI、字段、数字或文档段落。
3. **全屏证明态**：最高价值的结果、表格、流程或前后对比成为唯一主视觉，人物默认让位；
   仍保留最终口播主音频、字幕和底部章节进度。

### 字幕、进度与材质

- 删除倒计时、已播放时间和总时长。顶部只保留必要的短章节名或标签。
- 字幕严格最多两行，位于画面下部、章节进度上方。默认直接落字、使用细描边或轻底影，
  不用横跨大半画面的白色字幕卡；1080×1440 的字号不得低于 `36 px`。
- 章节进度位于最底部安全区，显示完整章节名；非当前章节不得低于 `18 px`。使用细线和
  小面积高亮，不用大块实色底板。
- 主卡使用双层柔影和极轻边缘高光；放大时阴影可增强，但不使用霓虹外发光或厚描边。
- Takeaway 改为跟随真实 UI 的短暂标注，不再常驻左下占据大块空间。

### 必检证据帧

- 开场：主卡中心位于距顶部 `45%–51%`，人物为向上悬挑的头肩近景，无倒计时。
- 默认态：主卡接近几何中心，整组视觉重心没有被字幕和进度拖到下半部。
- 关键放大：画面明确越过默认框，被口播点名的真实对象完整可读。
- 全屏证明：人物让位后信息更清楚，不是单纯把画面铺满。
- 最长字幕和最窄章节：字幕不低于 `36 px`，章节字不低于 `18 px`，不裁字、不省略。
